A1. Full Abstract

Modern organizations face increasingly sophisticated cyber threats, including ransomware, credential attacks, wireless network attacks, phishing, malware, and advanced persistent threats. Traditional cybersecurity approaches often rely on isolated tools requiring significant human intervention, resulting in delayed detection, inefficient incident response, and limited visibility across enterprise environments.

Security monitoring platforms, penetration testing tools, helpdesk systems, and security awareness programs currently operate independently. Furthermore, traditional security awareness training is often periodic and fails to provide employees with timely contextual guidance against emerging threats.

This research proposes the design and development of an AI-driven autonomous cyber defense and intelligent IT operations automation framework that integrates artificial intelligence, machine learning, security automation, and human-centered cybersecurity approaches.

The proposed framework will combine AI-powered Security Operations Center (AI-SOC) capabilities, network intrusion detection, wireless attack detection, automated penetration testing based on MITRE ATT&CK techniques, AI-generated security reports, endpoint micro-awareness notifications, automated incident escalation, IT helpdesk automation, and secure remote support infrastructure.

The research will develop an intelligent security framework consisting of:

  • AI-powered security monitoring
  • Automated vulnerability assessment
  • AI-assisted penetration testing
  • Wireless attack detection
  • Threat intelligence analysis
  • Autonomous security recommendations
  • Automated cybersecurity reporting
  • Secure remote support capabilities

The system will be implemented using open-source technologies including Wazuh, Zeek, Suricata, Kali Linux, MITRE ATT&CK, Ollama Large Language Models, GLPI, Zabbix, NetBox, and Keycloak.

The research will evaluate the framework based on threat detection accuracy, response time reduction, resource utilization, false positive rates, and user security engagement metrics.

The expected contribution is a practical and scalable open-source framework capable of improving cybersecurity resilience for enterprises, educational institutions, government organizations, and critical infrastructure environments.
