Firewall & IDS/IPS Deployment

Configuring Sophos and pfSense firewall environments and deploying IDS/IPS tools including Snort, Suricata, and Wazuh for network defense in a home lab environment.

Home Lab Project · pfSense · Sophos · Snort · Suricata · Wazuh

Overview

This project demonstrates practical network security implementation through firewall configuration and intrusion detection/prevention system deployment. The goal was to build a layered defense-in-depth architecture for a home lab environment that could detect and block malicious network traffic.

Architecture

The network security implementation uses a multi-layered approach:

  • Firewall Layer — pfSense and Sophos firewalls for network segmentation and access control
  • IDS/IPS Layer — Snort and Suricata for signature-based intrusion detection
  • EDR Layer — Wazuh for endpoint detection and response
  • Monitoring Layer — Centralized logging and alerting

Firewall Configuration

pfSense Setup

  • Installed pfSense on dedicated firewall hardware
  • Configured WAN and LAN interfaces with proper IP addressing
  • Set up VLANs for network segmentation (DMZ, IoT, Guest networks)
  • Implemented firewall rules for inter-VLAN traffic control
  • Configured NAT and port forwarding for specific services

Sophos Firewall

  • Deployed Sophos XG Firewall as secondary security layer
  • Configured web application firewall (WAF) rules
  • Set up SSL inspection for encrypted traffic analysis
  • Implemented application control policies

IDS/IPS Deployment

Snort Configuration

  • Installed and configured Snort on pfSense
  • Downloaded and updated Snort rules from Snort.org
  • Configured Snort for inline IPS mode
  • Tuned rules to reduce false positives
  • Set up custom rules for specific threat scenarios

Suricata Setup

  • Deployed Suricata as alternative IDS/IPS engine
  • Configured Emerging Threats (ET) rules
  • Set up Suricata for HTTP and DNS inspection
  • Integrated with Elasticsearch for log storage

Wazuh Implementation

  • Deployed Wazuh server for centralized security monitoring
  • Installed Wazuh agents on all endpoints
  • Configured file integrity monitoring (FIM)
  • Set up rootkit detection
  • Implemented security configuration assessment

Key Features

  • Defense in Depth — Multiple security layers for comprehensive protection
  • Real-time Detection — Immediate alerting on security events
  • Network Segmentation — VLAN-based isolation for different network zones
  • Traffic Inspection — Deep packet inspection for threat detection
  • Centralized Management — Single console for security policy management

Challenges and Solutions

Challenge: High false positive rates from IDS rules

Solution: Implemented rule tuning and whitelist configurations for legitimate traffic

Challenge: Performance impact from SSL inspection

Solution: Selective SSL inspection for high-risk traffic only

Challenge: Managing multiple security consoles

Solution: Integrated all systems into centralized SIEM for unified monitoring

  • Understanding of IDS/IPS rule management and tuning
  • Network segmentation best practices
  • Integration of multiple security tools into cohesive architecture
  • Performance optimization for security appliances

Future Enhancements
